# Alexa integration

Create an Alexa Skill to interact with the baby tracking app.

- Enable voice commands to log feedings, diaper changes, and sleep.
- Asking: when the baby last fed, changed a diaper, or slept.
- Provide summaries of the baby's activities.
- Set reminders for upcoming feedings or medications.
- Support multi-user access for family members.
- Eventually support multiple babies. Either tell the app which baby you are referring to in the commands or set a default baby.
- Optional: Allow customization of voice commands and responses.

Use Account Linking in Alexa Skill to connect the user's account with the baby tracking app.
Check if specific Alexa endpoints are needed or existing can be used.
Permission checking: How is unsufficient permission handled in Alexa Skills? Consider implementing fallback responses.
